# AcoreHost

代码位于独立 `acorehost` 分支；main 的工作流每 6 小时运行，无自派发，每个 job 最多 15 分钟。

- 每台只计一次综合结果。只有状态为 running 才报告运行成功；starting 等过渡状态先等待复查，不重复发送启动命令。
- 已知计划剩余超过 48 小时则不续；到期时间未知时也不续，并明确报未验证失败。
- 续期接口报告成功后，必须对比真实到期时间；读不到或没有推迟则失败。
- 不论续期能否进行，都检查状态；服务器停机时通过面板启动接口尝试启动并复查。状态未知或过渡状态不会盲目重复下发指令。
- restore 可能影响计划期限，语义未核明时不调用；挂起时仍会尝试启动并如实报告失败。
- 当前已知 API 不提供计划到期时间，续期能力受阻；需要面板实际网络请求或其他可靠的到期接口。
- 自测：`python -m unittest test_renew_acorehost`。API key 使用现有 Actions Secret。
